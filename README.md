# Кейсовня в Telegram: пошаговый гайд

## Самый простой запуск: GitHub Pages, без сервера

Папка `docs` содержит версию игры, которой сервер не нужен. Её бесплатно отдаёт GitHub Pages, она не засыпает и открывается мгновенно.

**Что работает:** кейсы, рулетка, апгрейд, забег, инвентарь, профиль. Прогресс хранится **только на устройстве игрока**: при входе с другого телефона или после очистки данных Telegram игра начнётся заново.
**Чего нет:** рейтинга, ленты чужих дропов, админ-панели и автоответа бота на `/start`. Для них нужен сервер (вариант ниже).

1. В репозитории откройте **Settings → Pages**.
2. В **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main** и папку **/docs**, нажмите **Save**.
3. Через минуту-две игра появится по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
4. В **@BotFather** отправьте `/setmenubutton`, выберите бота, пришлите этот адрес и текст кнопки, например «Играть». Кнопка появится слева от поля ввода в чате с ботом.
5. Необязательно: `/newapp` в BotFather создаст прямую ссылку на игру; картинки для бота лежат в папке `bot-assets`.

Чтобы обновить игру, замените `docs/index.html` и сделайте коммит: GitHub Pages обновит сайт сам.

## Полная версия: свой сервер с рейтингом и админкой

### Быстрее всего: свой VPS и одна команда

Подойдёт любой VPS с Ubuntu или Debian от 1 ГБ памяти. Подключитесь к нему по SSH и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/mark16042009-star/kejsovnya/main/deploy/install.sh | sudo bash
```

Скрипт спросит домен (можно пропустить), email для сертификата, логин и пароль администратора и — по желанию — токен Telegram-бота. Потом поставит Node.js 22 и Caddy, получит HTTPS-сертификат и включит автозапуск. Сайт сразу открывается и по `http://IP-сервера`.

**Вход на сайт.** Игроки регистрируются кнопкой «Войти» → «Регистрация» (логин и пароль). Без аккаунта тоже можно играть — прогресс хранится в браузере и переносится в аккаунт при регистрации. Админ входит под логином, указанным при установке, и получает раздел «Админ». Сменить пароль любого аккаунта: `cd /opt/kejsovnya && sudo -u kejsovnya env PASS='новый' node server.js set-password логин`. Свой домен не обязателен: по умолчанию используется бесплатный адрес вида `1-2-3-4.sslip.io` по IP сервера. Данные хранятся в `/opt/kejsovnya/data.sqlite`.

Обновить игру после изменений на GitHub: `sudo bash /opt/kejsovnya/deploy/update.sh`

Ниже — ручная установка и другие варианты хостинга.

Этот проект превращает сайт «Кейсовня» в мини-приложение (Telegram Mini App): игрок нажимает в боте кнопку «Играть», и игра открывается прямо внутри Telegram. Профили, рейтинг, лента дропов, апгрейды и админ-панель работают через ваш собственный сервер и базу данных.

## Что внутри

| Файл | Зачем |
|---|---|
| `docs/` | Версия для GitHub Pages: без сервера, прогресс на устройстве |
| `bot-assets/` | Аватар и обложка для бота |
| `deploy/` | Установка и обновление на своём VPS одной командой |
| `public/index.html` | Сама игра для сервера (та же, что на claude.ai, плюс подключение Telegram) |
| `public/adapter.js` | Прослойка: игра думает, что работает с хранилищем claude.ai, а на деле общается с вашим сервером |
| `server.js` | Сервер: отдаёт сайт, проверяет вход через Telegram, хранит данные, настраивает кнопку бота |
| `test.js` | Автотесты проверки входа и прав доступа (`npm test`) |
| `.env.example` | Шаблон настроек |

Серверу **не нужны сторонние пакеты**, только Node.js версии 22.5 или новее. Данные по умолчанию хранятся во встроенной базе SQLite (файл `data.sqlite`). Для PostgreSQL нужен один пакет: `npm install pg`.

## Как это устроено

```
Игрок → бот в Telegram → кнопка «Играть» → https://ваш-адрес (server.js)
                                              ├─ отдаёт игру (public/)
                                              ├─ проверяет подпись Telegram — узнаёт игрока
                                              └─ хранит данные: SQLite или PostgreSQL
```

Каждый запрос игры несёт подпись Telegram (`initData`). Сервер проверяет её токеном бота, поэтому выдать себя за другого игрока нельзя. Правила доступа те же, что были на claude.ai:

- **Свой прогресс** (баланс, инвентарь, статистика) читает и пишет только сам игрок.
- **Профили для рейтинга** видят все, а меняет каждый только свой.
- **Настройки экономики, кейсов и объявления** видят все, а меняют только админы.
- **Начисления и команды игроку** кладёт только админ, а читает только этот игрок.

## Шаг 1. Создайте бота

1. Откройте в Telegram **@BotFather** и отправьте `/newbot`.
2. Придумайте имя (например, «Кейсовня») и адрес бота, который заканчивается на `bot`.
3. BotFather пришлёт **токен** вида `1234567890:AAH...`. Это пароль от бота: никому его не показывайте и не выкладывайте в открытый доступ.
4. Узнайте свой Telegram ID, чтобы стать админом: напишите боту **@userinfobot**, он ответит числом.

## Шаг 2. Выберите, где запустить сервер

Telegram открывает мини-приложения **только по HTTPS**. Подойдёт один из вариантов:

### Вариант А. Railway или Render (проще всего)

1. Загрузите папку проекта в свой репозиторий на GitHub (файл `.env` не загружайте, он уже в `.gitignore`).
2. Создайте на Railway или Render новый **Web Service** из этого репозитория.
   - Команда сборки: `npm install`
   - Команда запуска: `npm start`
   - Версия Node: 22 или новее
3. Добавьте **базу PostgreSQL** (на Railway: New → Database → PostgreSQL; на Render: New → PostgreSQL) и скопируйте её адрес подключения в переменную `DATABASE_URL`.
   > На таких хостингах файл `data.sqlite` стирается при каждом обновлении. Поэтому здесь нужен именно PostgreSQL.
4. Хостинг выдаст адрес вида `https://kejsovnya.up.railway.app`. Это ваш `WEBAPP_URL`.

### Вариант Б. Свой сервер (VPS)

1. Арендуйте VPS (Timeweb Cloud, Selectel, Hetzner и т.п.) и привяжите к нему домен.
2. Установите Node.js 22, скопируйте проект, заполните `.env` и запустите: `npm start`. Чтобы сервер не падал, запустите его через `pm2` или `systemd`.
3. Для HTTPS поставьте перед ним Caddy. Конфиг `/etc/caddy/Caddyfile`:
   ```
   kejsovnya.example.com {
       reverse_proxy localhost:3000
   }
   ```
   Caddy сам получит и будет продлевать сертификат.
4. Здесь можно оставить SQLite: файл `data.sqlite` хранится на диске сервера. Делайте его резервные копии.

### Вариант В. Быстрая проверка со своего компьютера

1. Запустите сервер: `npm start`.
2. Запустите туннель, например `cloudflared tunnel --url http://localhost:3000`. Он выдаст временный HTTPS-адрес.
3. Используйте этот адрес как `WEBAPP_URL`. Подходит для теста, но не для постоянной работы: адрес меняется при каждом запуске.

## Шаг 3. Заполните настройки

Скопируйте `.env.example` в `.env` (или задайте переменные в панели хостинга):

| Переменная | Что указать |
|---|---|
| `BOT_TOKEN` | Токен от BotFather (обязательно) |
| `WEBAPP_URL` | Ваш HTTPS-адрес из шага 2 |
| `ADMIN_IDS` | Telegram ID админов через запятую, например `123456789,987654321` |
| `DATABASE_URL` | Адрес PostgreSQL, если используете базу (иначе будет SQLite) |
| `BUTTON_TEXT` | Текст кнопки в боте, по умолчанию «Играть» |
| `DEV_USER` | **Только** для проверки без Telegram на своём компьютере. На боевом сервере оставьте пустым! |

## Шаг 4. Запустите и проверьте

1. Запустите сервер. В логе должна быть строка вида
   `Кейсовня: http://localhost:3000  хранилище: postgres  админы: tg123456789`
   и сообщение `Бот: кнопка меню настроена, жду /start`.
2. Откройте своего бота в Telegram и отправьте `/start`. Бот ответит кнопкой «Играть», а слева от поля ввода появится кнопка меню.
3. Нажмите «Играть». В шапке под ником должно быть написано «в рейтинге», а у вас как у админа в меню появится пункт «Админ».

Сервер сам настраивает кнопку меню и отвечает на `/start`. Делать что-то ещё в BotFather не обязательно.

### Необязательно: прямая ссылка на игру

В BotFather отправьте `/newapp`, выберите бота, укажите название, описание, картинку 640×360 и тот же `WEBAPP_URL`. Получится ссылка вида `t.me/ваш_бот/kejsovnya`, которой удобно делиться.

## Проверка на своём компьютере без Telegram

```bash
npm run dev        # запускает сервер от имени тестового игрока "dev" с правами админа
npm test           # автотесты проверки подписи и прав доступа
```

Откройте `http://localhost:3000`, и игра будет работать с базой, как в Telegram.

## Что важно знать

- **Прогресс с claude.ai не переносится.** Это отдельное хранилище, поэтому в Telegram игроки начинают с нуля и стартового баланса.
- **Обновления приходят раз в несколько секунд.** Рейтинг, лента дропов, объявления и начисления обновляются каждые 3–5 секунд, а не мгновенно.
- **Игровая логика работает в браузере игрока.** Сервер надёжно знает, кто игрок, и не даёт трогать чужие данные. Но кейсы, апгрейды и забег считаются на телефоне. Опытный игрок может через инструменты разработчика подправить свой баланс. Для игры с виртуальными рублями это нормально. Если позже понадобится честный рейтинг на деньги, розыгрыш нужно перенести на сервер.
- **Только виртуальная валюта.** Не продавайте рубли игры и не меняйте выигрыши на реальные деньги и предметы: тогда это станет азартной игрой, а она регулируется законом и правилами Telegram.
- **Держите токен в секрете.** Если он утёк, выпустите новый в BotFather (`/revoke`) и замените в `.env`.
- **Резервные копии.** Для PostgreSQL включите бэкапы в панели хостинга, для SQLite копируйте файл `data.sqlite`.

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| В шапке «локально», рейтинг пустой | Сервер не принял вход. Проверьте `BOT_TOKEN`: он должен быть от того же бота, в котором открыта игра. |
| Бот не отвечает на `/start` | Не задан `WEBAPP_URL`, или этот же бот подключён к другому серверу через webhook. Сервер сам снимает webhook при запуске, но два запущенных сервера с одним токеном будут мешать друг другу. |
| Кнопка открывает пустой экран | Адрес не HTTPS или недоступен из интернета. Откройте `WEBAPP_URL` в обычном браузере и проверьте. |
| «Задан DATABASE_URL, но не установлен пакет pg» | Выполните `npm install pg` (или в настройках хостинга должна выполняться команда сборки `npm install`). |
| Нет пункта «Админ» | Ваш ID не указан в `ADMIN_IDS` или указан с ошибкой. Перезапустите сервер после изменения. |
